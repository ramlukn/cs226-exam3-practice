  • +0.5Computes the middle of the current range (lo + (hi - lo) / 2), not of the whole array
  • +1Picks the median of a[lo], a[mid], a[hi] correctly for every order of the three values
  • +0.75Moves the chosen value into a[hi] before calling partition, so partition still works unchanged
  • +0.25Keeps the base case and both recursive calls
  • Alternative: random pivot
  • +1.75Swaps a random index in [lo, hi] into a[hi] (or shuffles once up front). Expected O(n log n) on every input, but not the median-of-three that was asked for
  • −0.5Picks a median but still partitions around the old a[hi] (never moves it), so sorted input is still O(n²)
  • −0.125Minor logic or major syntax errors showing lack of understanding
private static void quickSort(int[] a, int lo, int hi) {
  if (lo >= hi) return;
  int mid = lo + (hi - lo) / 2;
  if (a[mid] < a[lo]) swap(a, mid, lo);
  if (a[hi] < a[lo]) swap(a, hi, lo);    // a[lo] is now the smallest of the three
  if (a[mid] < a[hi]) swap(a, mid, hi);  // a[hi] is now the median of the three
  int p = partition(a, lo, hi);
  quickSort(a, lo, p - 1);
  quickSort(a, p + 1, hi);
}

After the three swaps, a sorted range puts its true median at hi, so each partition splits it in half: O(n log n). An array of all-equal values is still O(n²) with Lomuto, because every element lands on one side.

public static boolean isMinHeap(int[] heap, int size) {

private int probe(K key) {
  int i = indexFor(key);
  int firstTombstone = -1;
  while (slots[i] != null) {                       // an empty slot ends the path
    if (slots[i].deleted) {
      if (firstTombstone == -1) firstTombstone = i; // remember only the first
    } else if (slots[i].key.equals(key)) {
      return i;                                    // live match
    }
    i = (i + 1) % slots.length;                    // linear step, wraps around
  }
  return (firstTombstone != -1) ? firstTombstone : i;
}

public boolean put(K key, V value) {
  if (key == null || value == null) throw new IllegalArgumentException();
  int i = probe(key);
  if (holdsKey(i, key)) {
    slots[i].value = value;                        // key exists: replace
    return false;
  }
  if (slots[i] == null) used++;                    // reusing a tombstone keeps used the same
  slots[i] = new Entry<>(key, value);
  size++;
  rehashIfNeeded();                                // after the new key is stored
  return true;
}

    int best = leftChild(i);

  heap[i] = heap[j];

  index.put(heap[i].item, i);    // BOTH moved entries get their new slot

private class KeyIterator implements Iterator<K> {

    while (curr == null && slot < buckets.length) {

    advance();
    return key;
  }
}

public static <V> int countWithinHops(Graph<V> g, V start, int k) {
  Map<V, Integer> dist = new HashMap<>();      // doubles as the visited set
  Queue<V> queue = new ArrayDeque<>();
  dist.put(start, 0);
  queue.add(start);
  int count = 0;

    V v = queue.remove();

        queue.add(w);
      }
    }
  }
  return count;
}

Write the Lomuto partition: pivot a[hi], values smaller than the pivot end up to its left and the rest to its right. Return the pivot's final index.

Tab inserts 2 spaces
Rubric and reference solution

3 pts. Start from 0 and add each item the answer earns; penalties come off at the end.

  • +1Takes pivot = a[hi] and starts the boundary i at lo
  • +1Scans j from lo to hi − 1, swapping a[j] into the left region and advancing i when a[j] < pivot
  • +0.5Finishes with swap(a, i, hi)
  • +0.5Returns i
private static int partition(int[] a, int lo, int hi) {
  int pivot = a[hi];
  int i = lo;                      // a[lo..i-1] < pivot
  for (int j = lo; j < hi; j++) {  // a[i..j-1] >= pivot
    if (a[j] < pivot) {
      swap(a, i, j);
      i++;
    }
  }
  swap(a, i, hi);                  // pivot between the two regions
  return i;
}

D34 pts

Sort a in ascending order with in-place heapsort: build a max-heap bottom-up, then repeatedly move the max to the end. Write the max-heap sink too. O(1) extra space.

Tab inserts 2 spaces
Rubric and reference solution

4 pts. Start from 0 and add each item the answer earns; penalties come off at the end.

  • +1Builds the heap by sinking indices n/2 − 1 down to 0
  • +1Sortdown: for end = n − 1 down to 1, swaps a[0] with a[end]
  • +1After each swap, sinks index 0 within the shrunk size (end), not a.length
  • +1sink picks the larger child, respects size, and stops when the parent is at least as large
public static void heapSort(int[] a) {
  int n = a.length;
  for (int i = n / 2 - 1; i >= 0; i--) sink(a, i, n);   // buildHeap: O(n)
  for (int end = n - 1; end > 0; end--) {
    swap(a, 0, end);       // max goes to the sorted tail
    sink(a, 0, end);       // heap is now a[0..end-1]
  }
}

private static void sink(int[] a, int i, int size) {
  while (2 * i + 1 < size) {
    int best = 2 * i + 1;
    if (best + 1 < size && a[best + 1] > a[best]) best++;   // larger child
    if (a[i] >= a[best]) break;
    swap(a, i, best);
    i = best;
  }
}

  return components;

private static <V> void dfs(Graph<V> g, V v, Set<V> visited) {
  visited.add(v);
  for (V w : g.neighbors(v)) {
    if (!visited.contains(w)) dfs(g, w, visited);
  }
}

3 pts. Start from 0 and add each item the answer earns; penalties come off at the end.

  • +0.5Looks up the slot in the map; throws for a null or missing item
  • +1Swaps the item into the last slot, removes it from the map, clears the slot and decrements size
  • +1If a real gap was filled (i < size), calls both sink and swim at i, because the filler can be too big or too small
  • +0.5Doesn't touch slot i when the removed item was already last
public void remove(T item) {
  if (item == null) throw new IllegalArgumentException();
  Integer i = index.get(item);
  if (i == null) throw new NoSuchElementException();
  swap(i, size - 1);                 // the item moves to the last slot
  index.remove(heap[size - 1].item);
  heap[size - 1] = null;
  size--;
  if (i < size) {                    // the filler at i may be too big or too small
    sink(i);
    swim(i);
  }
}

Return true if a has two equal values whose indices differ by at most k. One pass, O(n) expected time.

Rubric and reference solution

2 pts. Start from 0 and add each item the answer earns; penalties come off at the end.

  • +1Keeps a hash map from value to the most recent index where it was seen
  • +0.5Returns true when the current index minus the stored index is at most k
  • +0.5Updates the stored index on every step, so the closest earlier copy is used
public static boolean nearbyDuplicate(int[] a, int k) {
  Map<Integer, Integer> last = new HashMap<>();   // value -> latest index seen
  for (int i = 0; i < a.length; i++) {
    Integer j = last.get(a[i]);
    if (j != null && i - j <= k) return true;
    last.put(a[i], i);
  }
  return false;
}

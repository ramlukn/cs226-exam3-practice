public V put(K key, V value) {
  if (key == null || value == null) throw new IllegalArgumentException();
  int i = indexFor(key);
  for (Node<K, V> curr = buckets[i]; curr != null; curr = curr.next) {
    if (curr.key.equals(key)) {          // already there: replace, size unchanged
      V old = curr.value;
      curr.value = value;
      return old;
    }
  }
  Node<K, V> n = new Node<>(key, value);
  n.next = buckets[i];                   // new node at the head of the chain
  buckets[i] = n;
  size++;
  if (size > 0.75 * buckets.length) {   // after adding, check the load factor
    rehash();
  }
  return null;
}

size / buckets.length with two ints is integer division: 6 / 7 is 0. Multiply instead (size > 0.75 * buckets.length) or cast one side to double.

public void insert(T x) {
  if (x == null) throw new IllegalArgumentException();
  if (size == heap.length) {
    heap = Arrays.copyOf(heap, 2 * heap.length);   // full: double the array
  }
  heap[size] = x;                                   // new value at the first free slot
  size++;
  swim(size - 1);
}

private void swim(int i) {
  while (i > 0) {
    int parent = (i - 1) / 2;
    if (heap[i].compareTo(heap[parent]) >= 0) break;   // parent is no bigger: done
    swap(i, parent);
    i = parent;
  }
}

public static <T extends Comparable<T>> boolean isMinHeap(T[] a, int size) {
  if (a == null || size < 0 || size > a.length) throw new IllegalArgumentException();
  for (int i = 1; i < size; i++) {                  // every non-root node...
    if (a[i].compareTo(a[(i - 1) / 2]) < 0) {       // ...must be at least its parent
      return false;
    }
  }
  return true;                                      // size 0 or 1: trivially a heap
}

Checking each child against its parent covers every edge of the tree exactly once, with no bounds trouble: i runs over existing children, and every child has a parent.

public void insert(T item, int priority) {
  if (item == null || where.containsKey(item)) throw new IllegalArgumentException();
  heap[size] = new Entry<>(item, priority);
  where.put(item, size);         // record its index BEFORE swim (swim's swaps read the map's entries)
  size++;
  swim(size - 1);
}

public T removeMin() {
  if (size == 0) throw new NoSuchElementException();
  T best = heap[0].item;
  swap(0, size - 1);             // min goes to the end; last entry to the root
  where.remove(best);            // AFTER the swap, which would have re-added it
  heap[size - 1] = null;
  size--;
  if (size > 0) sink(0);
  return best;
}

The GIVEN swap writes both items' indices into where, so anything you remove from the map before a swap that touches it comes right back. Rule of thumb: finish moving entries, then delete the map entry.

  • +0.25Throws IllegalArgumentException for null or k outside 1..a.length
  • +1Uses a max-heap, e.g. new PriorityQueue<>(Collections.reverseOrder())
  • +0.75Adds freely while it holds fewer than k values
  • +1Once full, replaces the root only when x < peek()
  • +0.75Never holds more than k values
  • +1.25Returns peek() at the end: the largest of the k smallest
  • −1Puts all n values into the queue, or sorts the array
  • −0.5Uses a min-heap of size k (keeps the k largest instead)
  • −0.5Removes the root unconditionally once full
  • −0.125Minor logic or major syntax errors showing lack of understanding
public static int kthSmallest(int[] a, int k) {
  if (a == null || k < 1 || k > a.length) throw new IllegalArgumentException();
  // MAX-heap of the k smallest values seen so far: its root is the largest of them
  PriorityQueue<Integer> pq = new PriorityQueue<>(Collections.reverseOrder());
  for (int x : a) {
    if (pq.size() < k) {
      pq.add(x);
    } else if (x < pq.peek()) {   // x beats the largest of the kept k
      pq.remove();
      pq.add(x);
    }
  }
  return pq.peek();               // largest of the k smallest = the k-th smallest
}

Mirror image of top k: to keep the k smallest, the value you'd throw out next is the largest one kept, so it sits at the root of a max-heap. When the loop ends, that root is exactly the k-th smallest.
